# tuilane

**A local-first, modular terminal workspace for organizing tasks, projects, notes, ideas, and personal workflows.**

tuilane brings a command-line interface and keyboard-driven terminal UI together around local storage for personal workflows.

Current features include tasks, projects, notes, ideas, calendar, links, search, and an optional local assistant.

tuilane is in early development. Remote providers, external plugins, and synchronization remain future work.

## Get started

Install Rust and a native linker, then run from the workspace root:

```sh
cargo run -p tuilane
cargo test --workspace
```

See [configuration](docs/configuration.md) for setup, [ROADMAP.md](ROADMAP.md) for planned work, and [CONTRIBUTING.md](CONTRIBUTING.md) to contribute.
